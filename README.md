# MongoBackendClient

A custom JMeter Backend Listener that pushes sample results to **MongoDB** in near real-time using the MongoDB Java driver.

## Features

✅ Sends performance test metrics from JMeter to MongoDB  
✅ Supports batching of results for performance  
✅ Includes a per-test unique `run_id` (UUID) to group results  
✅ Captures assertions, response codes, messages, and optionally the response body  
✅ Supports transaction controllers aggregation  
✅ Fully extendable for custom metrics or metadata

## Configuration Parameters

| Parameter                        | Description                                                                            | Default                       |
|----------------------------------|----------------------------------------------------------------------------------------|-------------------------------|
| `mongo_uri`                       | MongoDB connection URI (e.g. `mongodb://user:pass@host:27017/db`)                      | `mongodb://user:pass@localhost:27017/perf_db` |
| `mongo_collection_name`           | Name of the MongoDB collection where results will be stored                             | `events`                      |
| `mongo_time_field`                | Field name used to store the timestamp of the sample                                     | `created_at`                  |
| `transaction.controller.prefix`   | Prefix to identify transaction controllers, e.g., `TC_Login`                             | `TC`                          |
| `batch.size`                      | Number of samples to insert per batch                                                  | `1000`                        |
| `save.response.body`              | Controls saving response body (`always`, `onError`, `off`)                             | `onError`                     |

## How it Works

- On test start, the plugin generates a unique `run_id` (UUID) to tag all results.
- Samples are processed recursively, capturing the main sample and any sub-results.
- Results are collected into a batch of MongoDB `Document` objects.
- Once the batch size is reached, the documents are inserted into the configured MongoDB collection using `insertMany()`.
- Metrics include assertions, timing, response codes, and JMeter thread group info.

## Installation

1. Download the latest release or build the JAR:

    ```bash
    .\gradlew shadowJar
    ```

2. Copy the generated JAR file into your JMeter `lib/ext` directory.

3. Restart JMeter.

4. In your JMeter test plan, add a **Backend Listener**, and select:

    ```
    io.github.mderevyankoaqa.es.visualizer.MongoBackendClient
    ```

5. Configure its parameters as shown in the table above.

## Notes

- Ensure your MongoDB collections are structured to accept the fields generated by this plugin.
- If you store response bodies, be aware of potentially large documents exceeding MongoDB’s document size limits (16 MB per document).
- The plugin writes data using standard MongoDB BSON documents for compatibility with the MongoDB driver.

## Compatibility

- **Supported JMeter**: 5.6.3
- **Minimum Java version**: 17
